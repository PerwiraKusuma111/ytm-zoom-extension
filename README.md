# Site Mobile Zoom (v2.0.0)

Ekstensi ringan untuk mengatur **zoom per-website** (tersimpan terpisah untuk tiap domain) di browser Android yang mendukung ekstensi (**Microsoft Edge Canary**, **Quetta**, **Kiwi**, **Mises**).

## Fitur
- **Zoom Terpisah Per-Website (50% – 300%)** — setiap domain menyimpan level zoom masing-masing. Situs yang belum diatur tetap 100% normal.
- **Preset Bawaan YouTube Music** — `music.youtube.com` otomatis siap pakai di **250%** + Kunci Anti Zoom aktif.
- **Kunci Anti Zoom Per-Situs** — matikan pinch zoom dan double-tap zoom (plus sembunyikan scrollbar) khusus di situs yang kamu pilih, tanpa mengganggu scroll atau slider lagu.
- **Mode Desktop UA Per-Situs** — ubah User-Agent ke Desktop Chrome khusus untuk domain tertentu, jadi opsi Situs Desktop global browser tidak perlu dinyalakan untuk semua web.
- **Daftar Situs Tersimpan & Reset** — lihat semua domain yang sudah diatur langsung dari popup dan hapus/reset kapan saja ke 100%.

## Download
- **CRX (Edge Canary Android):** `ytm-zoom-ext.crx`
- **ZIP (Quetta / Kiwi / Mises):** `ytm-zoom-ext.zip`
