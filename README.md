# YTM Mobile Zoom

Ekstensi ringan khusus untuk **YouTube Music** (`https://music.youtube.com/*`) di browser Android yang mendukung ekstensi (**Quetta**, **Microsoft Edge Canary**, **Kiwi**, **Mises**).

## Fitur
- **Auto Zoom 250% khusus YouTube Music** — web lain tetap 100% normal.
- **Preset & Slider Zoom (100% – 300%)** lewat popup ekstensi.
- **Kunci Anti Zoom** — matikan pinch zoom in/out dan double-tap zoom tanpa mengganggu scroll atau slider lagu.
- **Mode Desktop UA (Alternatif)** — ubah User-Agent khusus `music.youtube.com` ke Desktop Chrome sehingga Situs Desktop di browser bisa dimatikan dan Zoom tetap 100%.

## Download
- **ZIP (Quetta / Kiwi / Mises):** `ytm-zoom-ext.zip`
- **CRX (Edge Canary Android):** `ytm-zoom-ext.crx`
